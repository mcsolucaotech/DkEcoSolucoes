# Site DK Eco Soluções

Landing page estática (HTML/CSS/JS puro) da DK Eco Soluções. Os guias de desenvolvimento, publicação, SEO e qualidade ficam na raiz do repositório:

- Como rodar, publicar e configurar domínio/SEO: [`docs/onboarding.md`](../docs/onboarding.md)
- Arquitetura e arquivos: [`docs/architecture.md`](../docs/architecture.md)
- Verificações de qualidade (`npm run verify`): [`docs/quality.md`](../docs/quality.md)
- Produto e escopo: [`PRODUCT.md`](../PRODUCT.md)

## Conteúdo do site

- `index.html`: conteúdo, estrutura semântica e metadados.
- `assets/css/style.css`: layout responsivo.
- `assets/js/config.js`: campos configuráveis da operação.
- `assets/js/main.js`: menu mobile, links de contato e dados estruturados condicionais.
- `robots.txt`: diretivas para rastreadores.
- `CNAME`: arquivo a preencher quando o domínio for comprado/configurado.
- `img/`: logotipo, favicon e fotografias de apoio.
